# Bull City Blocks

Durham development news and urban planning coverage.

## Tech Stack

- [Astro](https://astro.build) - Static site generator
- [Tailwind CSS](https://tailwindcss.com) - Styling
- [GitHub Pages](https://pages.github.com) - Hosting
- [Umami](https://umami.is) - Analytics (self-hosted)

## Development

```bash
npm install
npm run dev
```

## Topics We Cover

- 🏢 High-rise and residential development
- 🚧 Infrastructure projects
- 📋 Permits and approvals
- 🗺️ Zoning changes
- 🏗️ Construction progress updates
- 🎉 Grand openings and closures
